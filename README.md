# AI家庭管家

📖 **[打开家长使用手册](ai-family-steward/使用手册.md)**：从怎么开始，到怎样一起商量、下次接着聊，都有可以直接复制的话。

家里的事，有时难在第一句话不知道怎么说。AI家庭管家陪你把眼前的一件事聊清楚，一起找个愿意试的小办法。

## 可以聊些什么

适合小学到高中阶段的家庭。家长、孩子可以各自使用，也可以一起讨论：

- 亲子沟通：着急、生气或觉得不被理解时，先听清彼此的表达。
- 家庭约定：商量家务、周末安排和 AI 使用边界。
- 共同项目：一起准备一顿晚饭，或完成一件家人都想参与的小事。

从一件事开始，不用填写长问卷。家长也承担行动，AI 提出的安排是草案，相关成员分别明确同意后再执行。

## 在常用的 AI 工具里开始

如果工具支持安装或加载 Skill，可以把下面这段话发给它：

```text
请帮我安装或加载“AI家庭管家”。
项目地址：https://github.com/xfsy-eve/AIfamily
技能文件夹：ai-family-steward
请按当前工具支持的方式操作，检查文件是否完整，并告诉我是否已成功；如果不支持，请直接说明。
```

装好后，在技能列表里找“AI家庭管家”，或者直接说：

```text
请用 $ai-family-steward 帮我聊一件家里的事：……
```

不同工具的安装、文件保存和提醒能力会有差别，AI 应说明实际能做到什么。支持本地记录时，只保存少量必要背景；可以随时说“别记”“你记了什么”“更正这条”或“忘掉这件事”。详细说明见[使用手册](ai-family-steward/使用手册.md)。
